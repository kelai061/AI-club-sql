# QQ-SQL 统一知识库与多模态数据库

> **定位**：可莱个人专属多模态知识档案室 ｜ **联动终端**：QQ 机器人 (AstrBot + SnowLuma) ｜ **呈现方案**：本地 Obsidian + Quartz 边缘静态站

---

## 一 · 六大资产目录体系

| 目录名 | 适用内容 | 典型来源 | 自动化录入支持 |
| --- | --- | --- | --- |
| `01-聊天记录/` | 重要讨论纪要、金句切片、争议记录 | QQ 群聊精华 | 手动整理 / Bot 精华沉淀 |
| `02-群友分享/` | 群友发布的深度长文、行业报告、技术干货 | QQ 群消息 / 转发链接 | 回复消息发送 `#存长文` 自动捕获 |
| `03-可莱输出/` | 可莱个人原创长文、深度复盘、学习体系笔记 | 本地创作 | 手动撰写为主（90%+） |
| `04-音视频库/` | 优质 B 站 / YouTube / 播客外链与时间戳笔记 | 外部媒体平台 | 发送 `#存视频 <链接>` 自动解析 |
| `05-技能库/` | 智能体 Skill、常用 Prompt 提示词、配置脚手架 | 实践经验 / 社区沉淀 | 发送 `#存技能 <名称>` 自动归档 |
| `06-多媒体资产/` | 文章配图、原图附件、音视频封面 | 本地引用 / Bot 抓取 | Bot 自动下载存放至 `images/` |

## 二 · 标准 YAML Frontmatter 元数据定义

本知识库内所有 Markdown 笔记必须在文档首部声明标准 YAML 属性：

```yaml
---
id: "20261003-share-001"          # 唯一编号：日期-类型-序号
title: "示例文档标题"              # 标题名称
type: share                       # 类型：chat | share | article | video | skill
author: "作者名"                  # 原作者或 QQ 昵称
source: "出处渠道"                # QQ群名 / B站 / 原创
created: "2026-10-03"             # 归档时间戳
tags:                             # 检索标签数组
  - AI
  - 架构
url: "https://..."                # 外部原始链接（非必填）
summary: "1~2 句话提炼核心要点"    # 摘要，供 QQ Bot 快速提取返回
published: false                  # 静态网站发布开关（true=推送公网，false=仅留本地）
---
```

## 三 · QQ Bot 交互协议速查

- **查询检索**：
  - `/查 [关键词]`：全局搜索标题、标签与摘要
  - `/查 skill [名称]`：精准调出对应技能的 Prompt 与用法
  - `/查 视频 [关键词]`：检索视频库并返回播放链接
- **快捷录入（仅限白名单管理员）**：
  - 回复某条长文消息发送：`#存长文 标题:xxx 标签:AI`
  - 发送：`#存技能 名称:xxx`
  - 发送：`#存视频 标题:xxx https://...`
